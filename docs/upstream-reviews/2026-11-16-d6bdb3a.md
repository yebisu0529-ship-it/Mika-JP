# 2026年11月16日の上流更新レビュー

上流0.1.44以降の候補から、HTTPの `HEAD` 応答に本文を書いて接続の再利用を妨げる問題を修正する。応答ステータスとヘッダーを保持して、同じ接続の次の `GET` に応答できるようにする。 [上流の修正](https://github.com/wangzan101/Mika/commit/55245084dd13ec1b444b08ac60d865f4db0fd499)

両方の候補ツリー、ファイル一覧とパッチハッシュを照合した。全差分の変更箇所を棚卸しし、新規範囲の主な通信、権限、同梱物、AIへの指示と採用するコードを静的に確認した。日本語版で変更する箇所はローカルHTTPサーバーの応答書き込み。認証後に出す本文の扱いだけを変える。テストは同じループバック接続で `HEAD` と `GET` を送り、先頭のヘッダー、本文の境界、続く `GET` の本文を確認する。

# Aqua Voiceとのフローティング表示の互換性

カプセルは従来 TYPE_ACCESSIBILITY_OVERLAY を使用していました。この種別は通常のアプリオーバーレイより上に配置され、ドラッグで位置を変えるだけでは優先順位を下げられません。

設定の「フローティング表示の互換性」から「他のアプリの上に表示」を許可すると、カプセル・カード・音声パネルの3枚を TYPE_APPLICATION_OVERLAY にそろえます。権限変更後の再描画では3枚を作り直し、ドラッグごとの削除・再追加は行いません。他のオーバーレイ利用者への余計な前面化を避けます。

権限は任意です。未許可の場合は既存の表示と通知へのフォールバックを維持します。権限を勝手に付与したり、Aqua Voiceの設定を変更したりしません。新しいAPKへの更新後、利用者が許可する必要があります。

Androidは通常のアプリオーバーレイ同士の順序を管理します。この変更は他社アプリの最前面を強制するAPIではありません。Aqua Voiceが通常のアプリオーバーレイを使う端末では、Mikaのカプセルを表示してからAqua Voiceを再表示してください。ユーザー補助オーバーレイを使う場合はそちらが上になります。

テストはレイヤー選択とAndroidのビルドを検証します。Aqua Voiceとの重なり順、ドラッグ、カード入力、権限取消しの実機確認は別途必要です。
